# 💰 Personal Finance Dashboard — Excel

> An interactive Personal Finance Dashboard built entirely in Microsoft Excel to analyze income, expenses, savings, budget utilization, accounts, payment methods, and financial trends.

---

## 📊 Project Overview

The **Personal Finance Dashboard** is an Excel-based data analytics project designed to transform raw financial transaction data into meaningful and interactive insights.

The project uses Excel formulas, PivotTables, PivotCharts, slicers, and dashboard design techniques to provide a consolidated view of financial performance.

The dashboard helps answer questions such as:

- How much income was generated?
- How much was spent?
- How much money was saved?
- What is the savings rate?
- How much of the budget was utilized?
- Which categories have the highest expenses?
- How does income and expense change month by month?
- Which accounts and banks have the most transactions?
- Which payment methods are used for expenses?
- How are savings goals distributed?

---

## 🎯 Project Objective

The main objective of this project is to:

1. Analyze personal financial transactions.
2. Calculate important financial KPIs.
3. Identify income and expense patterns.
4. Compare monthly income and expenses.
5. Analyze spending by category.
6. Monitor budget versus actual spending.
7. Analyze transactions by account, bank, and payment method.
8. Create an interactive dashboard for easy financial monitoring.
